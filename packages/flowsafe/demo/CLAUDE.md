# demo/

Runnable spike proving the full approval loop on workerd (suspend →
auto-queued D1 approval → restart persistence → decide → grant-minted
resume); the `pnpm spike` target, not shipped.

## Files

| File | What | When to read |
| ---- | ---- | ------------ |
| `worker.ts` | Complete spike Worker — grant-gated Mastra workflow, `DurableObjectRunner` subclass with `approvalGrantProvider` wired through `init()`, approval REST routes (header-auth demo), auto-create-approval-on-suspend, decide→DO-stub resume; curl script in the header comment | Seeing an end-to-end Worker + DO + approval-queue wiring, reproducing the spike |
| `wrangler.jsonc` | wrangler config — `RUNNER` DO binding (class `DemoRunner`, SQLite migration) + `DB` D1 database | Changing the spike's DO/D1 bindings or compat flags |
| `tsconfig.json` | Demo TS config (type-checked by the package `typecheck` script) | Debugging demo typecheck failures |

## Subdirectories

| Directory | What | When to read |
| --------- | ---- | ------------ |
| `.wrangler/` | Local wrangler/miniflare state (D1, DO storage) written by `pnpm spike`, gitignored | Never edit — generated by wrangler |

## Run

Automated pass/fail proof — starts the server on a dedicated port (8799,
`SPIKE_VERIFY_PORT` overrides), SIGKILLs the whole process tree mid-run,
proves the port refuses, restarts on the same persisted state, decides the
approval, asserts a forged raw resume fails closed, and asserts the run's
requester cannot decide their own approval (separation of duties); exits 0/1
(orchestrator: `../scripts/spike-verify.mjs`):

```bash
pnpm --filter @proofoftech/flowsafe spike:verify
```

Interactive server (port 8787; manual curl protocol in the `worker.ts`
header comment):

```bash
pnpm --filter @proofoftech/flowsafe spike
```
