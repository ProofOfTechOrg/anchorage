# Support

Anchorage is maintained as an open-source project. Public support is available
through the repository on a best-effort basis; there is no private support
channel or response-time SLA.

## Before opening an issue

1. Start with the [documentation index](docs/README.md) and the package README
   for [`@proofoftech/breakwater`](packages/breakwater/README.md) or
   [`@proofoftech/flowsafe`](packages/flowsafe/README.md).
2. Search [existing issues](https://github.com/ProofOfTechOrg/anchorage/issues)
   for the error, feature, or integration.
3. Reduce the problem to the smallest reproducible example and remove
   credentials, organization data, and other secrets.

## Where to ask

- Use the [question form](https://github.com/ProofOfTechOrg/anchorage/issues/new?template=question.yml)
  for setup and integration help.
- Use the [bug report form](https://github.com/ProofOfTechOrg/anchorage/issues/new?template=bug.yml)
  for reproducible defects.
- Use the [documentation form](https://github.com/ProofOfTechOrg/anchorage/issues/new?template=documentation.yml)
  for missing, incorrect, or confusing docs.
- Use the [feature request form](https://github.com/ProofOfTechOrg/anchorage/issues/new?template=feature.yml)
  for a new capability or public API proposal.

Include the affected package and version, `@mastra/core` version, Node or
Workers runtime, deployment topology, relevant configuration, and a minimal
reproduction. Replace secrets and organization identifiers before posting logs.

Do not report exploitable vulnerabilities in a public issue. Follow
[`SECURITY.md`](SECURITY.md) and use GitHub's private vulnerability-reporting
form.
